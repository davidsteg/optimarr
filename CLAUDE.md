# Optimarr

Every change that users would notice gets an entry under `## [Unreleased]` in `CHANGELOG.md`, and
every release follows [docs/RELEASING.md](docs/RELEASING.md): semantic version bumped in `VERSION`,
`backend/Cargo.toml` and `frontend/package.json`, user-facing release notes with a summary and
upgrade steps, released by merging to master. Never push, move or delete tags by hand.
